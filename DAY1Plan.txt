# Day 1 Plan – Project Setup for `metricmind-agentic-bi`

The goal of Day 1 is **not to build features**, but to create a professional development environment that will be used throughout the project.

**Estimated Time:** 5–8 hours

# Phase 8: Create Docker Compose

Create

```
docker-compose.yml
```

Example:

```yaml
version: "3.9"

services:
  postgres:
    image: postgres:16
    container_name: metricmind-db

    environment:
      POSTGRES_USER: postgres
      POSTGRES_PASSWORD: password
      POSTGRES_DB: metricmind

    ports:
      - "5432:5432"

    volumes:
      - postgres_data:/var/lib/postgresql/data

volumes:
  postgres_data:
```

Run

```bash
docker compose up -d
```

Check

```bash
docker ps
```
